# CivilEngg

A mobile-first web application for civil engineers — daily tools for calculation, unit conversion, and material density reference.

## Features

| # | Feature | Description |
|---|---------|-------------|
| 1 | 🧮 Calculator | Basic calculator supporting addition, subtraction, multiplication, and division with clear and backspace functions |
| 2 | 📏 Length Converter | Convert between mm, cm, m, km, inch, and feet |
| 3 | 📐 Area Converter | Convert between m², km², cm², mm², acre, and hectare |
| 4 | 📦 Volume Converter | Convert between m³, cm³, Liter, mL, ft³, and Gallon |
| 5 | 📋 Material Density Dataset | Reference table of 20 common construction materials with their density values (sand, cement, concrete, steel, gravel, soil, brick, asphalt, etc.) |
| 6 | 🔍 Live Search | Search and filter the material density table in real time |
| 7 | 🌙 Dark / Light Theme | Toggle between light and dark modes with radio buttons in the header; preference saved in localStorage |
| 8 | 📱 Mobile-First Design | Optimized for mobile screens (480px max-width) with large tap targets and responsive layout; also works on desktop |

## Tech Stack

- **HTML5** — single-file, no build step
- **CSS3** — custom properties for theming, mobile-first responsive design
- **Vanilla JavaScript** — all interactivity, no frameworks or dependencies

## Getting Started
